# 결과 설명자료 — 빈틈(BinTeum)

> 제출물 필수 4종 중 "결과 설명자료"입니다. 문제 정의 / Agent 구조 / 주요 기능 / 실행 결과 /
> 검증 방법·한계 / 센터 활용 방안을 담습니다. (기획서의 요약본이 아니라 **실행 결과 중심** 문서입니다.)

---

## 1. 문제 정의 (3줄)

1. 제주 방문은 1,300만 명대인데 **소수 핫플에 집중**되고, 그 결과는 대기·정체로 나타난다.
2. 기존 수단(지도앱 붐빔·분산관광 내비·블로그)은 **"지금 이 시각 + 이 사람의 제약"** 을 다루지 못한다.
3. 빈틈은 **읍면동 실측 유동인구**로 혼잡을 계산하고 **남은 하루 동선**을 다시 짠다.

## 2. Agent 구조 (실행 코드 기준)

| 단계 | 모듈 | 핵심 동작 | 검증 파일 |
|---|---|---|---|
| ① Router | `router.py` | 문장 → 제약카드(위치·종료시각·동행·수단·실내·예산·테마), 못 채우면 1회 되묻기 | `test_router.py` |
| ② Data | `data.py`, `hub.py`, `fields.py` | 5개 데이터셋 × 5단 폴백, 필드 별칭, 마스킹→결측 | `test_data.py`, `test_hub.py` |
| ③ Index | `index.py` | CI = 0.45·P_visit + 0.25·P_tour + 0.20·P_bus + 0.10·P_weather, 결측 재정규화 | `test_index.py` |
| ④ Planner | `planner.py` | 목적함수 3개(한산/이동최소/취향) + 하드 제약(영업시간·귀가·점심창·보행) | `test_planner_critic.py` |
| ⑤ Critic | `critic.py` | R1~R6 규칙, 위반 시 블랙리스트 + **1회** 재계획 | `test_planner_critic.py`, `test_pipeline.py` |
| ⑥ Reporter | `reporter.py`, `llm.py` | 카드·"왜 여기인가" 3줄·공유 텍스트·HTML, LLM은 숫자 가드 통과 시만 | `test_llm.py`, `test_pipeline.py` |
| 전체 | `pipeline.py` | 상태 경로 5개, trace JSONL, 산출물 저장 | `test_pipeline.py` |

## 5. 검증 방법과 한계

| 검증 축 | 방법 | 근거 파일 |
|---|---|---|
| 산식 | 재정규화·백분위·날씨항 단위 테스트(값까지 고정) | `tests/test_index.py` |
| 데이터 실패 | 200/502/403/타임아웃/캐시 5경로 가짜 전송 계층 | `tests/test_hub.py` |
| 제약 준수 | 실내·보행·예산·영업시간·귀가 복귀 | `tests/test_planner_critic.py` |
| 반려 루프 | 1회 제한 + 이력 기록 | `tests/test_pipeline.py` |
| 환각 가드 | 창작 수치가 든 LLM 응답 폐기 | `tests/test_llm.py` |
| 재현성 | 같은 입력 → 같은 동선 | `test_repeat_runs_are_stable` |
| 실행 흔적 | `out/traces/*.jsonl`(모든 Tool 호출·폴백·반려) | 실행 시 자동 생성 |

**한계(그대로 인정)**

1. 관광지 **내부 인원**은 공개 데이터가 없어 읍면동 단위로 근사 → "몇 명"이 아닌 **상대 순위**만 주장.
2. 읍면동 해상도 한계 — 같은 읍면동의 두 해변은 CI가 같다(50m 격자는 센터 반출 후 확장).
3. 공휴일·임시휴무 미반영(평일/주말 2분류).
4. "지금 vs 1시간 뒤"는 **추정**(일 단위 실측 × 시간대 가정 곡선)이며 화면에 '추정' 표기.
5. 유동인구(583)는 **2026-06-24~08-19 실측 수집분**이지만, 591·614·579·618은 프로젝트 미연결(403)로 **합성 스냅샷**이다. 허브가 2026-08-19 이후를 아직 적재하지 않아 기준일이 그 시점이다.

## 6. 센터 활용 방안

| 단계 | 내용 | 기대 효과 |
|---|---|---|
| **즉시(현재)** | 허브 공개 API만으로 동작. 센터 반출 불필요 | 누구나 재현 가능, 유지비 0 |
| **1단계** | 센터 `4-11 내국인 유동인구(읍면동)_v02` 연계 → **시간대별** 실측 | "지금 이 시각"이 추정 → 실측으로 승격 |
| **2단계** | `4-07 50m 격자` + `1-10 500m 카드` 연계 | 관광지 내부 밀도·소비 밀집 → "한산한데 상권은 산다" 추천 |
| **3단계** | `3-02 버스 노선별 이용 현황(시간대)` 연계 | 정류소 단위 혼잡·환승 부담 계산 |
| **정책 활용** | 도·관광공사가 **분산관광 정책의 사전 시뮬레이션** 도구로 사용(어느 읍면동에 수요를 돌릴 수 있는가) | 슬로우로드 등 기존 정책과 정합 |

연계 시 코드 변경 범위는 `DataPortal`의 정규화 함수 1개 추가 + 카탈로그 매핑 컬럼 확장입니다(설계상 분리되어 있음).
