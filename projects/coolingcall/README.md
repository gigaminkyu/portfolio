# 쿨링콜(Cooling Call) — 폭염 취약 사각지대를 먼저 찾아내는 담당자용 운영 도구

> 폭염특보가 뜨면 대구 **150개 행정동 중 "가장 위험한데 가장 손이 닿지 않는 동네"** 를 매일 자동으로 뽑고,
> 담당자가 바로 쓸 **안부 연락 문안**까지 만들어 주는 도구입니다. 숫자는 전부 코드가 계산하고, AI는 문장만 씁니다.
> **제1회 대구광역시 기후·환경·탄소중립 공공데이터 AI 활용대회**(부문1 아이디어 기획 제안) 출품작 — 2026-11-19 20:28 이메일 제출.

**시연 대시보드(공개)**: <https://gigaminkyu.github.io/portfolio/coolingcall/> — 설치 없이 브라우저에서 바로 열립니다.

## 1. 무엇을 하는가

| 단계 | 내용 |
|---|---|
| 수집 | 기상청 기온분석(대구 143, 일별) · 무더위쉼터 현황 · 행정동별 연령별 인구 |
| 계산 | 행정동 위험지수 = 폭염강도 0.30 + 고령취약도 0.40 + 대응결손 0.30 |
| 표출 | 위험 순위 지도·상위 10개 동·구성요소 근거·연도별 폭염 추이 |
| 문안 | 상위 동에 대해 담당자용 안부 연락 문안 생성(숫자는 슬롯 주입, 생성문의 숫자를 다시 대조해 불일치 시 폐기) |
| 승인 | 담당자가 화면에서 확인·수정 후 발송 — **자동 발송은 하지 않습니다** |

주간/야간(20시 이후 운영 쉼터만) 두 시나리오를 같은 산식으로 다시 계산합니다.
예: 달서구 월성2동은 주간 9위지만, 65세 이상 3,193명(24.0%)인데 20시 이후 여는 냉방 쉼터가 없어 야간에는 1위로 올라옵니다.

## 2. 실측 근거 (전부 원본을 내려받아 계산)

- 기상청 대구 일별 기온 **4,018일치(2015~2025)** → 2025년 폭염일 54일·열대야 24일·연 최고 37.4℃, 폭염강도 74.0
- 무더위쉼터 **1,195곳**, 행정동 인구 **150개 동**(65세 이상·75세 이상 재합산)
- 지도에 표시된 139개 동 경계와 지수표 150개 동을 대조(군위군 8개 읍면·신설 2개 동은 경계자료에 없어 지도 제외)
- **야간 공백**: 150개 동 중 109개 동(약 73%)에 20시 이후 운영 쉼터가 없음

| 데이터 | 제공기관 | 출처 |

| 기온분석(대구 143, 일별) | 기상청 국가기후데이터센터 | <https://data.kma.go.kr/stcs/grnd/grndTaList.do?pgmNo=70> |

## 3. 재현 절차

의존성: `openpyxl`(원본 엑셀 파싱), `weasyprint`(제안서 PDF — 화면·지수 산출에는 불필요).

```sh
python3 collect_kma_asos.py     # 기상청 기온분석 2015~2025 → data/kma_asos_daegu_daily.csv
python3 extract_daegu_geo.py    # 행정동 경계에서 대구 동 추출 → data/geo/daegu_dongs.geojson
python3 build_index.py          # 정제 + 위험지수 → data/processed/dong_index.csv, meta.json
python3 make_dashboard.py       # 단일 HTML 대시보드 → dashboard/index.html
python3 make_proposal.py        # 제안서 PDF(연락처는 CONTACT 환경변수로 주입)
```

지수표는 `data/processed/dong_index.csv`(150개 동 × 지표 20여 종)에 있고, 재실행해도 같은 값이 나옵니다.

## 4. 위험지수 산식

```
위험지수  = 0.30 × 폭염강도 + 0.40 × 고령취약도 + 0.30 × 대응결손

폭염강도   = 100 × (0.5·정규화(폭염일수) + 0.3·정규화(열대야일수) + 0.2·정규화(연 최고기온))
고령취약도 = 0.45·백분위(65세 이상 인구) + 0.35·백분위(65세 이상 비율) + 0.20·백분위(75세 이상 비율)
대응결손   = 100 × (1 − min(커버리지 / 300, 1))
커버리지   = 냉방 쉼터 수용인원 ÷ (65세 이상 인구 ÷ 1,000)      # 야간 모드에서는 20시 이후 운영 쉼터만
```

- 폭염일 = 일최고기온 33℃ 이상, 열대야 = 일최저기온 25℃ 이상(기상청 기준)
- 특보 단계는 실측 폭염강도(74.0)에 대한 배율 — 주의 0.80 · 경고 1.00 · 위험 1.15
- 인구 규모가 20배 차이 나므로 절대값 대신 **백분위(순위)** 로 축을 맞춥니다.

## 6. 한계 (제안서에 그대로 적은 내용)

- 기온은 대구 지점 1곳 기준입니다(동별 차이는 인구·쉼터 접근성에서 나옴).
- 지도 경계는 2018년 기준이라 군위군 8개 읍면과 2021년 이후 신설 동(혁신동·유천동)은 지도에 없습니다(표·지수에는 포함).
- 제출용 시연은 외부 LLM 호출 없이 같은 슬롯 구조를 결정론적 템플릿으로 재현했습니다. 운영 시에는 이 자리에 LLM을 붙이고 숫자 검증 계층은 그대로 유지합니다.
