01
독립 구현 · 합성 예제 검증

미수집을 0으로 읽지 않는 판단

DATA → DECISION

비어 있는 수치를 성과 없음으로 처리하면 잘못된 실행을 권할 수 있습니다. 관측 여부와 기간을 먼저 확인하고, 근거가 부족하면 판단을 보류합니다.

문제 · 사용자
업무 지표를 보고 다음 행동을 정하는 운영자를 가정한 독립 실험입니다. 실제 고객 적용은 확인하지 않았습니다.
기존 흐름
수집되지 않은 값과 측정된 0이 같은 값으로 처리될 수 있는 상황을 합성 예제로 재현했습니다.
구현 범위
관측 여부·기간·임계값을 검사해 hold / revise / maintain과 그 이유를 반환하는 공개용 축소 데모입니다.
판단 기준
null 또는 기간 불일치 → hold. 측정된 0 또는 기준 미달 → revise. 기준 충족 → maintain. 임계값은 데모용 가정입니다.
예외 · 권한
음수, 잘못된 기간, 정의되지 않은 관측 상태는 거부합니다. 권고만 반환하며 외부 작업은 실행하지 않습니다.
검증
null과 0의 구분, 기간 불일치, 세 가지 권고를 입력·출력 단위로 확인했습니다. AI 코딩 도구로 구현했고, 입출력과 예외 케이스는 실행해 확인했습니다.
미실증
실계정 상시 수집, 권고의 사업적 타당성, 매출 개선은 검증하지 않았습니다.
02
독립 구현 · 합성 예제 검증

실패해도 중복 실행하지 않기

DECISION → EXECUTION → RECOVERY

권고가 맞더라도 승인 만료나 재실행을 놓치면 안전한 자동화가 되지 않습니다. 실행 상태를 기록하고, 실패한 지점부터 복구하는 경로를 만듭니다.

문제 · 사용자
반복 작업을 승인하고 재시도하는 운영자의 실행 경계를 다루는 독립 실험입니다.
기존 흐름
실패 후 처음부터 재시도하면 이미 끝난 단계가 다시 실행될 수 있는 상황을 재현했습니다.
구현 범위
JSON 상태 파일, 작업 키, 승인 만료 검사, 단계별 완료 기록과 실패 복구를 구현한 합성 데모입니다.
판단 기준
승인이 유효할 때만 실행합니다. 같은 키로 이미 완료된 작업은 skipped로 처리하고, 실패한 작업은 마지막 완료 단계 다음부터 재개합니다.
예외 · 권한
외부 API와 실계정 작업은 없습니다. 데모가 관리하는 로컬 단계에서만 중복을 막으며, 분산 시스템의 exactly-once를 보장하지는 않습니다.
검증
2단계 실패 → 재실행 → 완료 → 다시 실행하면 skipped가 됩니다. 만료된 승인은 상태를 바꾸기 전에 거부됩니다. AI 코딩 도구로 구현했고, 입출력과 예외 케이스는 실행해 확인했습니다.
미실증
동시 실행, 외부 시스템의 부수 효과, 실서비스 장애 복구와 상시 운영은 검증 범위 밖입니다.
03
독립 구현 · 합성 예제 검증

주문·정산 CSV를 확인 가능한 결과로

INPUT → CHECK → USER OUTPUT

원본 파일을 정해진 형식으로 맞추고, 주문 수량과 정산 차이를 따로 검산해야 사람이 결과를 믿고 다음 업무로 넘길 수 있습니다. 이를 위한 로컬 도구와 교재를 만들었습니다.

문제 · 사용자
주문을 준비하고 정산을 확인하는 작은 가게 운영자를 가정했습니다. 실제 고객의 사용 여부와 절감 시간은 확인하지 않았습니다.
기존 흐름
행별 중복·상태와 금액 차이를 반복해서 확인하는 작업을 동봉한 합성 샘플로 정리했습니다.
구현 범위
HTML·JavaScript 도구와 CSV 양식, 정상·오류 샘플, 기대 결과, PDF 교재를 제작했습니다. 포트폴리오의 공개 데모는 이 중 정수 정산 대조 원칙만 재현합니다.
판단 기준
매출과 비용으로 관리잔액을 계산하고, 예상 입금과 실제 입금의 차이는 따로 표시합니다. 준비 대상은 사람이 직접 확인해 READY로 표시한 주문만입니다.
예외 · 권한
고객 개인정보 입력, 플랫폼 로그인, 발주, 환불, 세금 계산은 하지 않습니다. 원본 열 대응과 누락 주문 확인은 사용자가 맡습니다.
검증
합성 정산 예제에서 관리잔액 180000원과 입금 차이 20000원이 서로 다른 출력으로 나오는지 확인합니다. 실제 매출 지표가 아닙니다. AI 코딩 도구로 구현했고, 입출력과 예외 케이스는 실행해 확인했습니다.
미실증
판매용 교재 개정판의 공개 반영 여부와 실제 운영에서의 사용성은 별도 확인이 필요합니다. 유료 교재 원문과 비공개 파일은 공개하지 않습니다.
