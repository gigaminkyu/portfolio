# Mingyu Jeong — 정적 포트폴리오

한국어 중심 편집형 포트폴리오. 외부 폰트, 프레임워크, 패키지 설치, 브라우저 자바스크립트가 필요 없습니다.

## 수정과 미리보기

`content.json`에서 브랜드·문장·공개 글 링크를 수정합니다. `index.template.html`은 구조, `style.css`는 디자인입니다.

```sh
python3 build.py
python3 -m http.server 8765 --directory dist --bind 127.0.0.1
```

http://127.0.0.1:8765 에서 확인합니다. 배포 대상은 `dist/` 내용만입니다. QA 자료나 소스 문서를 웹에 게시하지 않습니다.

## GitHub Pages

부모의 콘텐츠·저장소 대상 검토 후 새 공개 저장소 또는 승인된 기존 저장소를 선택합니다. `dist/` 내용을 저장소의 `docs/`에 복사하고 Pages 설정을 해당 브랜치의 `/docs`로 지정할 수 있습니다. 모든 자산은 상대경로여서 `/저장소명/` 하위경로를 지원합니다. `.nojekyll`을 함께 배포합니다.

현재 저장소 생성, push, Pages 설정 및 실제 배포는 하지 않았습니다. 확인된 GitHub 프로필 링크는 아직 개인 프로필 CTA로 넣지 않았습니다. 공개 사례 링크는 구현 참고용으로 표시하며 직접 기여 범위를 확정하지 않았습니다.
